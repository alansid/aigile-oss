## 繁體中文

- **可以改用 PostgreSQL（選用）**：預設還是 SQLite，沒設 `DATABASE_URL` 就跟以前完全一樣，也照樣不用 `npm install`。設了 `DATABASE_URL=postgres://…`（PostgreSQL 16 以上）就改用 PostgreSQL：第一次啟動自動建表，之後的資料庫升級跟 SQLite 一樣啟動時自動套用。只有用 PostgreSQL 才要 `npm install`（裝連線套件 pg）；Docker 映像已經裝好。另有 `DATABASE_SCHEMA`、`PG_POOL_MAX`、連資料庫一起起來的 `docker-compose.postgres.yml`，以及從 SQLite 搬過去的 `scripts/sqlite-to-pg.js`（先確認目標是空的、整份一個交易、逐表比對筆數）。見 README「用 Postgres（選用）」
- **一則訊息多張截圖、哪裡都能貼**：一則訊息最多帶 4 張截圖，縮圖可以刪、可以再加，點開全螢幕看。卡片回覆、[需確認] 回覆、決策回覆、退回、交接的輸入框都能 Ctrl+V 貼截圖或按 📎
- **附件保存時間管理員可調**：預設改成 24 小時（原本 1 小時）。管理員在「管理員設定 › 稽核與儲存」可選 1／6／24 小時或 3／7／30 天，立刻生效、只影響之後上傳的檔；`FILE_TTL_HOURS` 只當初始值
- **專案 leader 管自己的專案**：leader 可以改名、封存、還原自己負責的專案，管成員與專案角色；頭像選單有「📁 專案管理」。「要你處理」最上面多了「👑 你負責的專案」：加入申請和待核准的技能先給 leader，有 leader 的專案過一天沒處理才給管理員。新增專案、永久刪除、邀請和帳號仍只有管理員能做
- **管理員設定頁**：只有管理員能做的事集中到頭像選單「⚙️ 管理員設定」（`/admin`）：待處理、群組設定、專案、邀請、帳號與救援、稽核與儲存、系統與備份。「成員管理」只留成員、角色、技能；舊網址會自動轉過去
- **關掉用不了的 AI 工具**：「管理員設定 › 群組設定」可以把 Claude Code、Codex、Antigravity CLI、Copilot CLI、其他各自關掉（至少留一個），關掉的不會出現在「我的 AI › 接入」
- **新站先登入**：全新的站先顯示登入頁，第一次登入先改帳號密碼，再進「第一次設定」引導（群組名稱、第一個專案、邀請成員、第一隻 AI），最後用一行啟動接上 AI；新站也看得到版本說明
- **忘記密碼**：還有一台裝置登入著，可以在「個人設定 › 帳號與登入」按「忘記目前密碼？」直接設新的（其他裝置會全部登出）；完全登不進來時請管理員「重設登入」
- **更多 AI 工具**：Antigravity CLI 和 Copilot CLI 都能接入、有一行啟動。Copilot CLI 目前只接入、不自動叫醒（免費版每月只有 50 次 premium 請求）

- **私訊關得掉**：「要你處理」裡的私訊可以按「已讀」直接清掉，同一隻 AI 連發的合併成一列；在總覽按「打開私訊」也會切到那隻 AI 的專案
- **回報問題與許願**：「說明」多了「回報問題」「許願」，草稿填好後在 GitHub 開預填的 issue，由你用自己的帳號送出；使用問題可以到 GitHub Discussions 問。`FEEDBACK_REPO` 可以指向自己的 fork，設 `0` 隱藏

## English

- **Optional PostgreSQL**: SQLite is still the default. Without `DATABASE_URL` everything works exactly as before, still with no `npm install`. Set `DATABASE_URL=postgres://…` (PostgreSQL 16 or later) to use PostgreSQL: tables are created on first start, and later database upgrades are applied at startup just like SQLite. Only PostgreSQL needs `npm install` (for the pg driver); the Docker image already has it. Also new: `DATABASE_SCHEMA`, `PG_POOL_MAX`, `docker-compose.postgres.yml` to start a database alongside, and `scripts/sqlite-to-pg.js` to move from SQLite (it checks the target is empty, copies in one transaction and compares row counts per table). See "Using Postgres (optional)" in the README
- **Several screenshots per message, paste anywhere**: one message can carry up to 4 screenshots; thumbnails can be removed or added, and open full screen. Card replies, [需確認] replies, decision replies, send-backs and handovers all accept Ctrl+V or 📎
- **Attachment retention set by admins**: the default is now 24 hours (was 1 hour). Admins pick 1/6/24 hours or 3/7/30 days in "Admin settings › Audit & storage"; it takes effect at once and applies to later uploads only. `FILE_TTL_HOURS` is just the initial value
- **Project leads manage their own projects**: leads can rename, archive and restore the projects they lead, and manage members and project roles; the avatar menu has "📁 Project management". "Needs your attention" starts with "👑 Projects you lead": join requests and skills awaiting approval go to the lead first and reach admins only after a day unhandled. Adding projects, permanent deletion, invites and accounts stay admin-only
- **Admin settings page**: everything only admins can do is under "⚙️ Admin settings" in the avatar menu (`/admin`): to-do, group, projects, invites, accounts & recovery, audit & storage, system & backup. "Member management" keeps members, roles and skills; old URLs redirect
- **Turn off AI tools you can't use**: in "Admin settings › Group settings" each of Claude Code, Codex, Antigravity CLI, Copilot CLI and Other can be turned off (at least one stays on); turned-off tools don't appear under "My AIs › Connect"
- **Sign in first on a fresh install**: a new site shows the sign-in page first. The first sign-in changes the account and password, then the first-time setup walks through the group name, first project, inviting members and the first AI, ending with the one-line start. Fresh installs show the release notes too
- **Forgot your password**: if another device is still signed in, use "Forgot current password?" in "Personal settings › Account & sign-in" to set a new one (all other devices are signed out); if you can't sign in at all, ask an admin to reset your sign-in
- **More AI tools**: Antigravity CLI and Copilot CLI can be connected, both with a one-line start. Copilot CLI is connect-only for now, with no automatic wake (the free plan has only 50 premium requests a month)
- **Refreshed messages page**: compact and full views; times show hours and minutes with day dividers, and a line marks where you last read. The "awaiting your reply" bar is gone; the count moves onto the "For me" tab
- **DMs can be cleared**: DMs in "Needs your attention" have a Read button, and several from the same AI merge into one row; "Open DM" from the overview switches to that AI's project
- **Report a bug or request a feature**: Help has "Report a bug" and "Request a feature". Fill in the draft and it opens a prefilled GitHub issue that you submit with your own account; usage questions go to GitHub Discussions. Point `FEEDBACK_REPO` at your fork, or set it to `0` to hide the links
- **Skill templates from "+ Add skill"**: pick the project, then a template (3 recommended for the project's AI roles, with search, categories and a side preview), or upload your own `SKILL.md`

Upgrade: if you cloned it, `git pull`, then `docker compose up -d --build`; if you use the image, pull the new `ghcr.io/alansid/aigile-oss` and restart. **One database upgrade** (`migrations/003_files_message.sql`, which only adds an index) is applied automatically at startup; nothing to do by hand. Staying on SQLite needs no change. To switch to PostgreSQL, set `DATABASE_URL` as described in "Using Postgres (optional)" and move existing data with `scripts/sqlite-to-pg.js`. Attachment retention now defaults to 24 hours instead of 1; if you don't set `FILE_TTL_HOURS` and want to keep 1 hour, change it in "Admin settings › Audit & storage". On the AI side, paste the one-line start again (or reconnect with the onboarding text) to switch to the new scripts.
