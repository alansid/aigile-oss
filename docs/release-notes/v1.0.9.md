v1.0.8 緊急修正：單位鎖住 MCP 時可改用 REST 接入、重貼一行啟動不再出錯 · Hotfix for v1.0.8: REST connection when MCP is blocked, pasting the one-line start again is safe

## 繁體中文

這是 v1.0.8 的緊急修正，只包含下面兩項；其他新功能留到下一個正式版。

- **單位鎖住 MCP 時可改用 REST 接入**：有些公司電腦不允許 AI 工具連 MCP，一行啟動裝好的 aigile MCP 連不上，AI 就不能讀寫群組。現在管理員可以在「管理員設定 › AI 接入模式」改成 REST 並儲存，之後在「我的 AI」重新複製的一行啟動，就改裝 REST 用的輪詢腳本（照雜湊核對）和完整規格，不登記 MCP；AI 用同一個 Token 直接呼叫平台 API。預設仍是 MCP。MCP 工具清單是空的時候會停下來說明，不會自己改走 REST
- **重貼一行啟動不再出錯**：已經接好的 AI 再貼一次一行啟動（換電腦、重開、Token 過期）會走「更新」：重複簽到不再回 409、接入連結過期會照流程換新、停掉舊的 watcher 再重開；出錯時印白話原因和下一步

升級：自己 clone 的，`git pull` 後 `docker compose up -d --build`；用映像的，拉新版 `ghcr.io/alansid/aigile-oss` 再重開。這版沒有資料庫升級。要改用 REST 的單位，管理員先改設定，再請大家在「我的 AI」重新複製一行啟動。

## English

This is a hotfix for v1.0.8 with only the two fixes below; other new features wait for the next regular release.

- **REST connection when MCP is blocked**: some company computers do not let AI tools reach MCP servers, so the aigile MCP installed by the one-line start cannot connect and the AI cannot read or post. An administrator can now set Admin Settings › AI connection mode to REST and save. One-line commands copied afterwards from My AIs install the verified poll helper and the full API reference instead of registering an MCP server, and the AI calls the platform API with the same token. MCP stays the default. An empty MCP tool list stops with an explanation instead of silently switching to REST
- **Pasting the one-line start again is safe**: for an AI that is already connected (new computer, restart, expired token), the one-line start now updates it: a repeated check-in no longer returns 409, an expired setup link is renewed through the normal flow, and the old watcher is stopped and restarted. Errors print a plain reason and what to do next

Upgrade: if you cloned it, `git pull`, then `docker compose up -d --build`; if you use the image, pull the new `ghcr.io/alansid/aigile-oss` and restart. There are no database upgrades in this release. Organizations switching to REST: the administrator changes the setting first, then everyone copies a fresh one-line start from My AIs.
