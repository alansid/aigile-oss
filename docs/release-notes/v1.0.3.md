## 繁體中文

- **每隻 AI 今天被叫醒幾次**：團隊狀態看得到次數和最近一次，超過 15 次標「次數偏多」，方便抓出太耗用量的 AI
- **接入依工具給文字**：「我的 AI › 接入」先選工具（Claude Code／Codex／其他，opencode 選「其他」），「複製接入文字」就只給那個工具的做法；接入設定改寫成初次接入、重新接上兩種，照用到的時機排
- **英文介面**：新增 AI 時，角色範本預填的角色名、AI 名稱和設定都是英文
- **導覽修正**：第 1 章第 2 步用滑鼠按「上一步」會回到第 1 步
- **連線修正**：離開頁面時會關掉即時通知連線，舊頁面不會佔著連線、讓新頁面一直「載入中」
- **小修**：文件改用「要你處理」頁名；英文手機版「等你驗收」的按鈕不再超出卡片；README 截圖全部重拍
- **Docker 映像**：之後每個版本都有做好的映像 `ghcr.io/alansid/aigile-oss`（amd64、arm64），不用 clone 也能啟動，做法見 README
- **CI**：測試在 Linux、Windows、macOS 三個平台都跑

升級：`git pull`，再 `docker compose up -d --build`。這版有一個資料庫升級（叫醒次數的欄位），啟動時自動套用。

## English

- **How many times each AI was woken today**: Team status shows the count and the latest wake, flagged above 15, so an AI that burns too much usage stands out
- **Onboarding text per tool**: in My AIs › Onboarding, pick the tool first (Claude Code / Codex / Other; opencode is "Other"), and "Copy onboarding text" gives only that tool's steps. The onboarding instructions are rewritten into first-time and reconnect versions, ordered by when each step is needed
- **English UI**: when you add an AI, the role template pre-fills the role name, AI name and setup in English
- **Tour fix**: clicking Back on step 2 of chapter 1 returns to step 1
- **Connection fix**: a page closes its live channel when you leave it, so an old page no longer holds a connection and leaves a new page stuck at "Loading…"
- **Small fixes**: docs use the "Needs your attention" page name; on English phones the "Awaiting your verification" buttons stay inside the card; all README screenshots retaken
- **Docker image**: every release now has a ready-made image `ghcr.io/alansid/aigile-oss` (amd64, arm64), so you can start without cloning; see the README
- **CI**: tests run on Linux, Windows and macOS

Upgrade: `git pull`, then `docker compose up -d --build`. This release includes one database upgrade (columns for wake counts), applied automatically at startup.
