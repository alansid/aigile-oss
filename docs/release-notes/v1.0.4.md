Codex 有事才叫醒、一行啟動、批次標記 · Codex wakes only when needed, one-line start, batch marking

## 繁體中文

- **Codex 有事才叫醒**：Codex 不再一直在前景等，有人找它時才在背景跑一輪；開著 Codex 視窗時，@ 它的訊息直接送進那個對話。背景那輪用比較省的模型（`AIGILE_CODEX_MODEL`、`AIGILE_CODEX_EFFORT` 可改），你開著的視窗不換模型
- **一行啟動**：「我的 AI」多了「複製一行啟動」，貼到終端機就會檢查腳本、跑接入檢查、裝好 MCP 與技能、開待命，再打開 Claude Code 或 Codex；Claude Code `/clear` 後會自己接回來
- **Codex 接卡做到待 commit**：被叫醒的 Codex 會把交給它的卡做到「改好、測完、等 commit」，有事用 [需確認] 問；commit、push、合併、部署照樣要所屬的人同意
- **一次標記多則**：「要你處理」的「要你回覆」和「[需確認]」都可以勾選、全選，再按「不用回（N）」或「標為已處理（N）」。標為已處理的 [需確認] 在訊息頁顯示灰色「已處理（未回覆）」，AI 讀到也知道
- **新增 AI 的導覽**：導覽第 1 章在新增 AI 表單裡分 4 小步帶；表單被擋下時會捲到出錯的欄位，錯誤寫在那一欄底下
- **`npm start` 可以指定埠號與位址**：`npm start -- -p 8080`、`--host 127.0.0.1`，也可以用環境變數 `HOST`；參數不對會印說明並停下
- **修正**：啟動時遇到 Token 失效以外的錯誤（例如網路一時斷掉）不會再把你登出；改專案網址後馬上新增專案，建議的網址不會再是舊的
- **文件**：Codex、opencode 的接法整理到 `docs/connect-your-ai.md`（中英）；README 先寫一行啟動

升級：自己 clone 的，`git pull` 後 `docker compose up -d --build`；用映像的，拉新版 `ghcr.io/alansid/aigile-oss` 再重開。這版沒有資料庫升級。AI 那邊重新貼一次「一行啟動」（或照接入文字重新接上），就會換成新的待命腳本。

## English

- **Codex wakes only when needed**: Codex no longer waits in the foreground; it runs one background round only when someone needs it, and while the Codex window is open, mentions go straight into that chat. Background rounds use a cheaper model (set with `AIGILE_CODEX_MODEL` and `AIGILE_CODEX_EFFORT`); the window you have open keeps its own model
- **One-line start**: My AIs has "Copy one-line start". Paste it into a terminal and it checks the scripts, runs the onboarding check, installs the MCP and skills, starts standby and opens Claude Code or Codex; Claude Code reconnects by itself after `/clear`
- **Codex works cards up to "waiting for commit"**: a woken Codex takes cards handed to it to "changed, tested, waiting for commit" and asks with [需確認]; commit, push, merge and deploy still need its owner
- **Mark several at once**: on "Needs your attention", both "Awaiting your reply" and the [需確認] posts have checkboxes and select all, then "Not needed (N)" or "Mark handled (N)". A [需確認] marked handled shows a grey "Handled, no reply" label on the messages page, and AIs see it too
- **Add AI tour**: chapter 1 of the tour walks through the Add AI form in 4 small steps; when the form is rejected it scrolls to the field with the problem and shows the error under it
- **Choose the port and address for `npm start`**: `npm start -- -p 8080`, `--host 127.0.0.1`, or the `HOST` environment variable; a bad option prints help and stops
- **Fixes**: an error at startup other than an invalid token (for example a dropped connection) no longer signs you out; right after renaming a project URL, a new project suggests the right URL
- **Docs**: Codex and opencode setup now lives in `docs/connect-your-ai.en.md`; the README starts with the one-line start

Upgrade: if you cloned it, `git pull`, then `docker compose up -d --build`; if you use the image, pull the new `ghcr.io/alansid/aigile-oss` and restart. No database upgrade in this release. On the AI side, paste the one-line start again (or reconnect with the onboarding text) to switch to the new standby scripts.
