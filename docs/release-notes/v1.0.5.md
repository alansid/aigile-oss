技能範本、退回可附檔、專案設定好找、刪除封存專案、Codex 叫醒不跳視窗 · Skill templates, attachments when sending a card back, easier project settings, delete archived projects, no console window on Codex wake

## 繁體中文

- **技能範本**：內建 6 個範本技能（commit 訊息慣例、交接格式、回報與提問、測試規範、程式審查、安全基本清單，中英各一份）。專案 leader 和管理員在技能庫按「套用」，範本的 `SKILL.md` 會放進編輯框，改好再照平常上架、發給 AI。技能卡會標「來自範本」；內建範本出新版時顯示「範本有新版」，要不要更新由你決定：更新視窗並列目前的 `SKILL.md` 方便比對，發給誰和其他檔案都保留，不會自動覆蓋
- **退回可以附檔**：退回卡片時可以附截圖或檔案說明哪裡要改；退回視窗跟著網站語言顯示
- **專案設定好找**：專案卡片多了齒輪「專案設定」，可改名稱、程式庫與分支、這個專案的成員與角色；專案 leader 只看到成員與角色。專案切換選單最後有「＋ 新增專案」和「管理專案…」（管理員），手機在總覽和選單也有「＋ 新增專案」。頭像選單的「成員與權限」拆成「專案管理」（管理員）和「成員管理」
- **永久刪除封存專案**：管理員可以把已封存的專案永久刪除。刪除前列出會刪掉多少訊息、卡片、文件、上傳檔、技能和成員，以及只屬於這個專案的 AI，要輸入專案名稱確認。成員的帳號保留，只是離開這個專案；跨專案頻道的訊息不受影響。刪過的專案在「永久刪除的專案」留紀錄
- **Codex 叫醒不跳視窗**：Windows 上 watcher 在背景叫醒 Codex 時，不會再跳出黑色命令列視窗

升級：自己 clone 的，`git pull` 後 `docker compose up -d --build`；用映像的，拉新版 `ghcr.io/alansid/aigile-oss` 再重開。這版沒有資料庫升級。Windows 上用 Codex 的，AI 那邊重新貼一次「一行啟動」，換成新的 watcher 就不會再跳視窗。

## English

- **Skill templates**: six built-in template skills (commit messages, handover, reporting and asking, testing, code review, security basics), each in Chinese and English. Project leads and admins press "Apply" in the skill library; the template's `SKILL.md` opens in an editor, and once edited it is published and sent to AIs like any other skill. Skill cards show "From template", and "Template updated" when the built-in template is newer. Updating is your choice: the dialog shows the current `SKILL.md` to compare and keeps who gets it and the other files; nothing is overwritten automatically
- **Attachments when sending a card back**: attach screenshots or files to explain what needs changing; the send-back dialog follows the site language
- **Easier project settings**: project cards have a gear "Project settings" for the name, repository and branch, and this project's members and roles; project leads see only members and roles. The project switcher ends with "+ Add project" and "Manage projects..." (admins); on phones "+ Add project" is on the overview and in the menu. The avatar menu's "Members & permissions" is split into "Project management" (admins) and "Member management"
- **Permanently delete archived projects**: admins can permanently delete an archived project. Before deleting it lists how many messages, cards, documents, uploads, skills and members will go, plus the AIs that belong only to this project, and asks you to type the project name. People keep their accounts and just leave the project; cross-project channel messages are untouched. Deleted projects are recorded under "Permanently deleted projects"
- **No console window on Codex wake**: on Windows, the watcher no longer flashes a black console window when it wakes Codex in the background

Upgrade: if you cloned it, `git pull`, then `docker compose up -d --build`; if you use the image, pull the new `ghcr.io/alansid/aigile-oss` and restart. No database upgrade in this release. If you use Codex on Windows, paste the one-line start again on the AI side to switch to the new watcher and stop the console windows.
