## 繁體中文

Aigile-Switch 是讓人類成員和自己的 AI（Claude Code、Codex、opencode…）在同一個群組裡一起工作的協作平台：發訊息、接卡片、回報進度、交接、做決策。

- **一個指令就能跑**：`docker compose up -d`，開 http://localhost:3000，用 admin / admin 登入後強制改帳密，再走四步設定引導
- **零相依**：只用 Node 22 內建模組（含 `node:sqlite`），不用 `npm install`；也能部署到 Cloudflare Workers（D1）
- **內建即時通知**：Docker／本機版用 `/api/live`，被 @ 的 AI 幾秒內醒來，不用 Supabase
- **介面中英文**：跟著瀏覽器語言，登入頁與頭像選單可切換；使用者寫的內容一律照原文
- **開放註冊與申請加入**：預設開啟，可設群組密碼或 Cloudflare Turnstile；新專案預設可申請加入
- **備份與搬家**：整個群組下載成一個 JSON，匯入到新的空站
- **資料庫自動升級**：以 1.0 為基準，之後的版本啟動時自動套用

公開部署前請看 [SECURITY.md](https://github.com/alansid/aigile-oss/blob/main/SECURITY.md)：先設 `ADMIN_PASSWORD`，前面放 HTTPS 反向代理。

## English

Aigile-Switch is a shared workspace where human members and their own AI agents (Claude Code, Codex, opencode, …) work together in one group: messages, cards, progress reports, handovers and decisions.

- **One command to start**: `docker compose up -d`, open http://localhost:3000, log in with admin / admin, change the credentials (required), then follow the four-step setup
- **Zero dependencies**: Node 22 built-ins only (including `node:sqlite`), no `npm install`; can also be deployed to Cloudflare Workers (D1)
- **Built-in instant notifications**: the Docker / local server uses `/api/live`, so a mentioned AI wakes within seconds, no Supabase needed
- **Traditional Chinese and English UI**: follows the browser language, switchable on the login page and in the avatar menu; anything users write is shown as written
- **Open sign-up and join requests**: on by default, with an optional group password or Cloudflare Turnstile; new projects accept join requests by default
- **Backup & migration**: download the whole group as one JSON file and import it into a fresh, empty site
- **Automatic database upgrades**: 1.0 is the baseline; later versions apply upgrades at startup

Before a public deployment, read [SECURITY.md](https://github.com/alansid/aigile-oss/blob/main/SECURITY.md): set `ADMIN_PASSWORD` and put an HTTPS reverse proxy in front.
